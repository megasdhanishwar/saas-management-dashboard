# Orbit SaaS Management Dashboard

A responsive React + Vite frontend for managing SaaS users, subscriptions, pricing plans, usage, and revenue analytics.

## Run locally
1. Install Node.js (18+ recommended).
2. Extract this ZIP and open the folder in VS Code.
3. Open the terminal in the project folder.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local URL printed by Vite.

## Build
Run `npm run build` to create the production build in `dist/`.

## Included
- Overview dashboard with KPI cards, revenue chart, subscription mix, and activity feed
- Users, subscriptions, plans, and analytics pages
- Search, status filters, sorting, pagination, and date-range controls
- Add/edit/delete pricing plan modal with validation and confirmation
- Toast notifications and loading/empty states
- Responsive sidebar, tables, and mobile layouts
- Local demo data; changes are held in React state and reset on refresh

This is a frontend demo and does not connect to a backend or persist changes to a database.
